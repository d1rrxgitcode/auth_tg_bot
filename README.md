# auth_tg_bot# 🤖 Telegram Captcha Bot

Бот для защиты публичных Telegram-групп от спама. При вступлении нового участника бот отправляет капчу прямо в чат — пока пользователь её не решит, он не может писать сообщения. Если капча не пройдена — участник исключается.

---

## ⚙️ Как работает капча

1. Новый участник вступает в группу
2. Бот отправляет в чат арифметическую задачу (`a + b = ?`) с 4 вариантами ответа
3. У пользователя **3 попытки** и **5 минут** на решение
4. Любое сообщение в чат до прохождения капчи засчитывается как неверная попытка и удаляется
5. При верном ответе — капча-сообщение удаляется, пользователь остаётся в группе
6. При исчерпании попыток или истечении времени — участник исключается (soft kick: бан + разбан, может вернуться)

## 🚀 Установка и запуск

### Требования

- Python 3.11+
- Токен бота от [@BotFather](https://t.me/BotFather)

### 1. Клонировать репозиторий

```bash
git clone https://github.com/d1rrxgitcode/auth_tg_bot.git
cd repo
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Настроить `.env`

```bash
cp .env.example .env
```

Заполнить `.env`:

```env
TOKEN=your_bot_token_here
```

### 4. Запустить

```bash
python main.py
```

## ⚙️ Конфигурация

| Параметр | Файл | По умолчанию | Описание |
|---|---|---|---|
| `TOKEN` | `.env` | — | Токен бота |
| `_timeout` | `captcha_service.py` | `300` сек | Время на прохождение капчи |
| Количество попыток | `captcha_service.py` | `3` | Попытки при создании записи |

## 🔐 Права бота в группе

Бот должен быть **администратором** со следующими правами:

| Право | Зачем |
|---|---|
| Управление участниками | Исключение пользователей |
| Удаление сообщений | Удаление капчи и сообщений нарушителей |
| Отправка сообщений | Отправка капчи в чат |

Также в [@BotFather](https://t.me/BotFather) → Bot Settings → **Group Privacy** нужно выключить (Disable), чтобы бот получал все сообщения группы.

## 📋 Логирование

Логи выводятся в stdout в формате:

```
2026-03-14 12:00:00 | INFO     | bot.handlers.captcha | New member joined | user_id=123 user=Александр chat_id=-100...
```

Уровень по умолчанию — `INFO`. Для отладки можно переключить на `DEBUG` в `main.py`:

```python
setup_logging(logging.DEBUG)
```

| Уровень | Что логируется |
|---|---|
| `INFO` | Вступления, попытки, кики |
| `WARNING` | Чужие капчи, ошибки удаления сообщений |
| `ERROR` | Критические сбои (не удалось кикнуть) |
| `DEBUG` | ID сообщений, новые вопросы для повтора |
